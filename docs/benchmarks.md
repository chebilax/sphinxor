# Benchmarks

No measurements have been taken yet. This file is a placeholder until there is a working extraction pipeline and a real corpus to run it against (see [`testing.md`](testing.md)).

It will eventually cover, with numbers traceable to a specific run against a specific corpus:

- False positive / false negative rates on a corpus of real open source repositories in the target framework.
- Comparison against a hand-written Semgrep/CodeQL rule targeting the same class of issues, to justify the cost of a dedicated tool.
- Performance (time, memory) on repositories of varying size.

No numbers are published here until they've actually been measured. An empty benchmarks page is more honest than an invented one.
